# 设计摘要（归档）

本文档收纳本仓库已经定稿的路线说明；契约与格式仍以 **`ARCHITECTURE.md`**、各 README 与代码为准。

---

## 1. 定位

- 不是造“单一巨型网络替代引擎静态评估”
- 是让轻量网络学习**人类候选着与局面语义**
- 搜索负责战术穷尽与最终验证

---

## 2. 当前短期产品

当前短期主产品不是搜索引擎，而是**复盘系统**。

当前复盘 MVP 目标是：

- `policy`
- `value`
- `danger`
- `attack`

补充说明：

- `tactical` 暂时不是最小复盘系统阻塞项
- 模型不是唯一信息源
- 复盘系统允许并鼓励结合：
  - **真理引擎**
  - **滑动窗口前后文**

---

## 3. 当前训练路线

当前不建议长期同时共训所有头。

推荐顺序是：

1. 先继续做强 `policy + trunk`
2. trunk 接近平台后，冻结 trunk 单独训练 `value`
3. 再训练 `danger`
4. 再训练 `attack`

---

## 4. 长期路线

长期仍然是搜索引擎。

但顺序是：

1. 先在复盘系统里证明这些头有解释价值
2. 再把真正有效的头转成搜索收益

---

## 5. 关于 Teacher 与真理引擎

- 外部强引擎可以作为**真理校验器**或**对照源**
- 不默认把外部终评当成唯一训练真值
- 若使用外部 Teacher，应显式标注文档与实验用途
