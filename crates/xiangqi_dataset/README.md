# xiangqi_dataset

这是维护者侧最小数据工具 crate。

当前定位已经收口为最小辅助工具，只保留：

- PGN 读取与清理
- ICCS 记谱转 UCI
- 未来自对弈数据预处理的最小地基

注意：

- 它不再承担主规模训练数据生产
- 当前主训练数据路线固定为 `px0 / lc0` 风格外部数据
- 当前仓库内已经不再保留 `XRSH` 分片与本地搜索标注链路

## 什么时候还会用到它

- 你要读或清理少量 PGN
- 你要做后续自对弈数据预处理
- 你要补少量离线数据辅助脚本

## 什么时候不该再用它

- 你要承担正式训练数据格式
- 你要再造一套本地大规模 shard 格式
- 你要恢复旧的人类 XRSH 训练路径

这些现在都应该回到 `px0` 主线去做。
