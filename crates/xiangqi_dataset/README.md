# xiangqi_dataset

这是维护者侧最小数据工具 crate。

当前定位已经降级为辅助工具，只保留：

- PGN / 词表相关工具
- XRSH 相关工具
- 小批量本地搜索标注

注意：

- 它不再承担主规模训练数据生产
- 当前主训练数据路线已经切到 `px0 / lc0` 风格外部数据

## 什么时候还会用到它

- 你要做少量规则联调
- 你要做少量本地搜索补点
- 你要验证旧的人类数据支线

## 什么时候不该再用它

- 你要扩主规模训练数据
- 你要快速做 value 数据扩样本
- 你要跑长期 baseline

这些现在都应该回到 `px0` 主线去做。
